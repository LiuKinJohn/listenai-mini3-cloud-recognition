# 功能、选项与验证记录

快照日期：2026-10-27。设备为单键、无触控的 Mini3，屏幕 240×240，摄像头取景区 240×180，使用标称 8 GB TF 卡。配置为 8 MiB PSRAM（AP 3 MiB、CP 5 MiB），板型 `arcs_mini3`，版本字符串 `3.0.3`。

## 交互与界面

首页两页应用网格，首屏时钟、识云、相机、相册，第二页设置。选中应用使用浅蓝圆角描边。强调色主色 `#5AAAF5`，高光 `#8DCEFF`。

| 按键 | 动作 |
| --- | --- |
| 单击 | 下一项；时钟切换样式；相册 / 云册下一条；识云结果切换详情。 |
| 双击 | 打开、确认、拍摄或执行当前选项。 |
| 按住约 0.9 秒以上但不足 3 秒后松开 | 返回；首页打开系统菜单。 |
| 按住满 3 秒 | 关机，松开不再触发返回。 |

系统菜单提供熄屏待机、重启、清除配网、恢复出厂和关机。重启、清除凭据、恢复出厂有二次确认。

## 应用

时钟支持段码、Rubik、点阵，联网自动校时，显示北京时间。相机支持原图、色块、单色、CRT；选择拍照或切换特效后双击执行。相册读取 TF 卡 JPEG。

识云强制使用原片，双击拍照后通过经过校验的 TLS 上传；结果包含云型、模型自评等级及依据。unknown 显示为“暂无法识别”。单击切换依据页，长按返回。云册关联照片与 JSON，单击下一条。

照片：`/SD:/IMG_XXXX.JPG`；云册：`/SD:/CLOUD/CLD_XXXX.JSON`。模型自评不等同于统计准确率。IP 城市与天气没有接入，因此页面中的“位置待获取”“气象数据待获取”仍是占位。

| Wi-Fi | 状态、信号、地址、自动连接、热点配网、配网状态、热点名称、密码、配置地址、清除凭据。 |

热点配网会扫描网络并广播临时 WPA2 热点；手机连接后打开 `http://192.168.4.1`。提交后切回普通联网，成功才保存凭据。单 Wi-Fi 接口无法同时维持热点与普通联网。

## 已知限制

- 声音总开关、按键音、息屏时长、自动连接开关目前主要保存值，尚未完整驱动行为。
- 亮度 / 音量菜单显示 20～100，但实际设置函数下发 10～90，存在偏移。
- 云册没有删除管理界面；拍摄和识云依赖可读写的 TF 卡。
- 发布构建默认云身份清空，旧云语音应用不带可用默认凭据。
- `CONFIG_OTA_DISABLE_APP_UPDATE=y` 阻止官方应用固件自动覆盖；没有关闭全部资源更新。
